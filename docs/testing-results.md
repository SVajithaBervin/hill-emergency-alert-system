# Testing Results

The project documentation reports validation of the following scenarios.

| Test Scenario | Expected Output | Result |
|---|---|---|
| Safe State | Green LED + SAFE on LCD | PASS |
| Landslide Alert | Red LED + Buzzer + LCD | PASS |
| Heavy Rain Alert | Yellow LED + 2 Beeps + LCD | PASS |
| SOS Alert | Red LED + Fast Buzzer + SOS message | PASS |
| Blynk Cloud Connection | Device online + notification | PASS |
| ThingSpeak Logging | Time-series graphs | PASS |

The documented prototype was tested through Wokwi simulation and breadboard-based hardware testing.
